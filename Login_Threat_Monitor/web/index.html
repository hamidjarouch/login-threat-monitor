Rule definitions & CSV format

BURST: failure count for one IP reaches the threshold within the inclusive time window. SUCCESS_AFTER_FAILURES: a successful login follows enough failures for the same IP and user within the window. Success resets that account's sequence. MULTI_ACCOUNT: failures target at least the threshold number of distinct usernames from one IP in the window.

BURST and MULTI_ACCOUNT emit when the threshold is crossed, then re-arm when the count drops below it. Counts are evaluated at each event. Equal timestamps follow CSV row order. Duplicate rows count as separate events.

Required columns: timestamp,user,ip,status. Time: YYYY-MM-DD HH:MM:SS; all rows must use the same timezone. Status: failed or success. Invalid input rejects the entire file. Maximum 20,000 events.
