Login Threat Monitor | Authentication Log Investigation

A small investigation workspace for a common security question: when do failed logins become a pattern worth reviewing?

The project analyzes authentication CSVs using three explainable rules:
• Repeated failures from one source within a configurable time window.
• A successful login after repeated failures for the same account and source.
• Failures targeting several accounts from one source.

Each alert includes supporting events and a suggested next step. The dashboard supports severity filtering, event search, and CSV/JSON reports.

The demo uses synthetic data. Alerts indicate suspicious patterns, not proof of compromise. Shared networks and legitimate user mistakes remain important sources of false positives.

Stack: Python, HTML, CSS, JavaScript.
Focus: log analysis, sliding time windows, input validation, detection testing and clear investigation evidence.
